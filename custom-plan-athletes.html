Custom-plan athlete setup

Set up athletes on custom plans

Review your athletes’ training while staying in control of the feedback you share. This walkthrough covers activation, activity analysis, workout imports, and coach alerts.

The walkthrough uses example athlete data. The written instructions below cover the same workflow.

Activate your athlete

  1. Open Athletes. Search by name, or select Any status to include deactivated athletes.
  2. Open the athlete’s profile and select Settings.
  3. If activation is unavailable, open Integrations and check whether you need to reconnect TrainingPeaks.
  4. Click Activate, choose Custom plan, and confirm you have the athlete’s consent to analyse their data.
  5. Select Coach review, then click Activate athlete.

Wait for the TrainingPeaks sync to finish. You can then review the athlete’s activities and their analysis. If a connection warning remains, resolve it before expecting activities to sync.

Import structured workouts

The coach TrainingPeaks connection does not provide the prescribed workout structure. Activity analysis can still give you useful insights, but it cannot fully assess compliance with the prescribed session without that structure.

Install the PlanMyPeak Importer browser extension . Open Workout Library and select Import from TrainingPeaks to bring your structured workouts into PlanMyPeak.

PlanMyPeak tries to match the planned session to an imported workout. When it finds a match, it can use the structure for fuller compliance analysis. See Workout library for more detail.

Configure coach alerts

In Alert Rules, choose the metrics and thresholds you want to monitor, enable the rule, and save. Turn on Metric-alert emails if you want email notifications. See Athlete alerts for the available rules and delivery settings.

For custom plans, activity reports and alerts are for you, the coach. Athletes do not receive automated PlanMyPeak emails, and weekly review emails are not available.

Scale your coaching without diluting your judgment.
